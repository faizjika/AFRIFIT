# AFRIFIT

An AI-inspired fitness and wellness dashboard built around Nigerian food, practical workouts, hydration, and community.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL, usually http://localhost:5173. Create a production build with `npm run build`.

## Included

- Daily activity dashboard with hydration tracking and weekly movement chart
- Workout library with filters and a timed session flow
- Nigerian food search, meal logging, and daily macro totals
- Community feed with likes, posts, and a weekly walking challenge
- Profile goals and a sample coach chat

The app currently uses browser storage and local demo data. The coach replies are sample responses, not generated by an AI service. Base44 authentication, database entities, uploads, subscriptions, and server-side AI are not connected; those require the corresponding Base44 project and service credentials.
